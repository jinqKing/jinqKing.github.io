适合谁

你不一定要是这门课的学生。

大学里真正有意思的东西，经常藏在课表、教室和时间之间。此课希望把这些信息整理得更容易发现。

01

认真上课的人

查课程、看上课时间和地点、整理自己的课程表，再从课表直接找到对应建筑。

02

想旁听、想“蹭课”的人

对哲学、历史、数学、计算机或任何陌生领域突然好奇？先看看校园里有哪些课程正在发生，再决定要不要进一步了解。

03

校友、访客与校外人士

不在校园里，也可以借课程和地图看见一所大学真实的知识日常：什么课在哪里开，哪些建筑承载着怎样的课堂。

此课能做什么

课表很好用，地图也应该很优雅。

此课不是只做一个课程搜索框。课程是内容，课表是你的视角，地图是它们发生的地方。

课程查询

搜索课程、教师、院系与上课安排，快速找到你关心的课堂。

个人课程表

把课程整理成清晰、适合日常查看的周课表，让时间和地点始终在同一个视图里。

校园地图

把课程投影到校园建筑中，找楼、找教室，也看看周围此刻正在发生什么。

Web 与 App

网页和 App 围绕同一套课程、账户与校园体验生长，尽量让使用保持连续。

更多学校

从一所学校开始，慢慢连接更多校园。

此课目前从北京大学等已接入校园逐步生长，其他学校与校区也在陆续接入。不同学校的课程、作息、校区和地图不会被强行套进同一套数据里，而是逐个整理、验证和接入。

独立项目

此课是一个单人开发的独立、公益校园项目。它从一个很简单的问题开始：如果课程信息不再只是散落在教务系统、通知、表格和群聊里，我们能不能更自然地看见校园？

所以它慢慢有了课表、课程查询、建筑与地图，也开始连接更多学校和校区。方向一直很简单：开放、克制、好用，让校园里的公共信息更容易被看见。

发现此课

如果你刚好在搜索这些，也许你找对了地方。

北京大学课程 / 北大课程查询：想了解今天或这学期有哪些课程、老师在哪里上课、某个院系有哪些课堂，可以从此课的课程查询开始。

北大课表 / 大学课程表工具：需要一张干净、适合手机查看的个人课表，此课可以把课程、时间和地点放回同一个视图。

北大地图 / 燕园地图 / 教室地图：如果你知道课程名字，却不知道教学楼在哪里，地图可以继续接住这条信息。

旁听课程 / 蹭课 / 大学公开课堂：如果你只是对另一门学科好奇，此课也可以作为发现入口。先知道有什么、何时发生、在哪里，再遵守实际课程的开放规则。

高校课程查询 / 校园探索：此课并不只准备停留在一所学校。更多学校正在陆续接入，希望以后能从课程、课表和地图重新认识更多校园。
