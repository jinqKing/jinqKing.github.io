For everyone curious

你不一定要是这门课的学生。

大学里真正有意思的东西，经常藏在课表、教室和时间之间。此课希望把这些信息整理得更容易发现。

One small product

课表很好用，地图也应该很好看。

此课不是只做一个“课程搜索框”。它更像一个逐渐长出来的校园界面：课程是内容，课表是你的视角，地图是它们发生的地方。

课程查询

搜索课程、教师、院系与上课安排，快速找到你关心的课堂。

个人课程表

把课程整理成清晰的周课表。它首先要是一张真正舒服、日常愿意打开的课表。

校园地图

把课程投影到校园建筑里，找楼、找教室，也看看周围此刻有什么课。

Web 与 App

围绕同一套课程和校园体验生长，让信息不被困在某一个入口。

“从一张课表开始，逐渐连接课程、建筑、校区与学校。”

Independent project

此课是一个单人开发的独立、公益校园项目。它从一个很简单的问题开始：如果课程信息不再只是散落在教务系统、通知、表格和群聊里，我们能不能更自然地看见校园？

所以它慢慢有了课表、课程查询、建筑与地图，也开始尝试连接更多学校和校区。方向一直很简单：开放、克制、好用，让校园里的公共信息更容易被看见。

愿你始终保持好奇 · Keep Being Curious.

关于旁听与“蹭课”：此课只帮助发现公开可获得的课程信息，不代表课程一定对外开放。实际旁听、进入教学空间或参与课堂，请尊重学校管理规定、课程要求与授课教师意见。
Discover cike

如果你刚好在搜索这些，也许你找对了地方。

北京大学课程 / 北大课程查询：想了解今天或这学期有哪些课程、老师在哪里上课、某个院系有哪些课堂，可以从此课的课程查询开始。

北大课表 / 大学课程表工具：需要一张干净、适合手机查看的个人课表，此课可以把课程、时间和地点放回同一个视图。

北大地图 / 燕园地图 / 教室地图：如果你知道课程名字，却不知道教学楼在哪里，地图可以继续接住这条信息。

旁听课程 / 蹭课 / 大学公开课堂：如果你只是对另一门学科好奇，此课也可以作为发现入口。先知道有什么、何时发生、在哪里，再遵守实际课程的开放规则。

校园探索：校园不仅是一组建筑。课程、讲座、活动和人在时间里共同构成它。此课想做的，是让这些关系更容易被看见。
